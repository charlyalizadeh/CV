\section{Projects}

\entry{Data Center Fabric as Code}{Go, Ansible, Jinja2, containerlab, FRRouting, Docker}{}{\href{https://github.com/spikte/data_center_fabric}{github.com/spikte/data\_center\_fabric}}
\begin{itemize}
  \item Declarative intent to running network: a Go controller turns a YAML description of the fabric (servers, spines, tenants, VLAN segments, management subnet) into the containerlab topology and the Ansible inventory, with Build / Start / Stop / Restart actions.
  \item Ansible roles render FRRouting configurations from Jinja2 templates (one per routing design: eBGP underlay and overlay on the same or separate sessions) and reload FRR only when a configuration changes.
  \item Multi-tenant leaf-spine fabric with a VXLAN EVPN overlay (L2VNI per VLAN segment, L3VNI per tenant); servers configured with VLAN-aware Linux bridges and one netshoot container per tenant VLAN.
  \item Connectivity test by the controller
\end{itemize}

\entry{Netsim -- Network Simulator}{C++, Qt}{}{\href{https://github.com/spikte/netsim}{github.com/spikte/netsim}}
\begin{itemize}
  \item Network simulator with a GUI, written from scratch: L2 switch forwarding, MAC table, ARP, VLANs (access/trunk), partial LLDP and STP; L3 IPv4 forwarding and ICMP.
  \item Cisco-style CLI on simulated devices: \texttt{show mac address-table}, \texttt{show vlan}, \texttt{show ip route}, static routes, \texttt{ping}, \texttt{traceroute}.
\end{itemize}

\entry{packet\_viz -- Traffic Origin Analyzer}{C, raw sockets, MaxMind GeoLite2}{}{\href{https://github.com/charlyalizadeh/packet_viz}{github.com/charlyalizadeh/packet\_viz}}
\begin{itemize}
  \item Captures incoming TCP/IPv4 packets with a raw socket and maps each source to its autonomous system (AS) and location, using longest-prefix match in a binary IP trie built from the MaxMind prefix tables (downloaded and SHA-256 verified).
\end{itemize}

\entry{spikte\_chat -- Chat Server}{C++, Linux sockets, epoll, TLS, SQLite}{}{\href{https://github.com/spikte/spikte_chat}{github.com/spikte/spikte\_chat}}
\begin{itemize}
  \item Client/server chat on the Linux networking stack: single-threaded epoll event loop, raw TCP or TLS transport, multiple rooms, account and message persistence in SQLite, Argon2 password hashing.
\end{itemize}
